# DWH-SM2-0003: ThermoPro series in separate window graphs (outdoor + ThermoPro, decisive windows)

> ThermoPro series in separate window graphs (outdoor + ThermoPro, decisive windows)

**Type:** default
**Epic:** [DWH-SM2](DWH-SM2)
**Status:** in_progress
**Blueprint:** [implementation-story-blueprint](implementation-story-blueprint)

## Goal

Give the thermal-comfort expert separate per-window graphs that pair the outdoor air
temperature with the measured ThermoPro 5NP corridor series, so the decisive cases
(indoor measured temperature above 30 °C while outdoor stayed below the design-day peak)
can be read directly from one chart each. Companion deliverable to [DWH-SM2-0002](DWH-SM2-0002):
same window selection, new standalone charts intended as attachments for the expert reply
(draft kept in `_inbox/`, outside git).

## Requirements

### R1: Separate ThermoPro window graphs for every ThermoPro-era window

For every quasi-stationary window with ThermoPro coverage (2025-08-10..12, 2025-08-19..21,
2026-07-08..11, 2026-08-19..21), a separate graph `window_thermopro_<start>_<end>.png` exists
in `analysis/`, alongside the combined graphs from DWH-SM2-0002.

**Acceptance Criterion:** All four `window_thermopro_*.png` files exist in `analysis/`,
including both decisive windows 2025-08-19..21 and 2026-07-08..11.

### R2: Graph content and reproducible generation

Each graph plots, in one axes: the ČSN 73 0540-3 design day (grey dashed), outdoor ambient
temperature (green, sensor sm2_01), the 5NP corridor min–max band (ThermoPro measured,
purple fill), the measured 5NP-S3 corridor line (top floor, section 3 — the hottest sensor),
the 27.0 °C operative and 30.0 °C air limit lines, and orange shading for frozen sensor days.
Generation is integrated in `analysis/quasistationary_selection.py` (function
`plot_window_thermopro`, called from the main loop), so re-running the script regenerates
all four PNGs.

**Acceptance Criterion:** `plot_window_thermopro` is defined and invoked in
`analysis/quasistationary_selection.py`, drawing the design day, outdoor line, 5NP band,
5NP-S3 line, both limits and frozen shading.

## Notes

Created: 2026-09-23. Window selection logic unchanged from DWH-SM2-0002 (A-days ≤ 30 °C
outdoor, ≥ 3 consecutive real days; frozen weekends excluded). Source semantics follow the
refined 0002 wording: ThermoPro = measured temperatures on floor corridors (1st/5th floor),
Atrea = section-average extract air (lower bound). Visual verification 2026-09-23: both
decisive-window PNGs confirmed — 5NP-S3 clearly above the 30 °C line (peaks ~30.9 / ~31.1 °C),
corridor band above 27 °C for most of both windows while outdoor peaks stay at 27–29 °C;
the outdoor line dips to ~14–15 °C at night (normal diurnal cycle, not a data gap).
